# File handling

The repository contains analysis code and documentation. The separate data archive contains derived tables, stored predictions and run records. Original battery objects, model weights and manuscript files are distributed separately by their respective owners or are not part of this release.

Verify archive and file hashes before use. Raw reconstruction loads Python pickle files, which can execute code; use only trusted, hash-checked upstream objects. Run reproduction and training in new output directories. Existing results are retained rather than overwritten.

The main replay runs locally and does not upload inputs or results. Training requires a separately obtained BatteryLife checkout at the documented commit.
